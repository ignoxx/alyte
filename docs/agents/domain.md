# Domain docs

Engineering skills consume Alyte as a single domain context.

## Before exploring

- Read the root `CONTEXT.md`.
- Read every ADR under `docs/adr/` that affects the task.
- Proceed silently if a referenced domain document does not exist.

Use the glossary's canonical terms in issues, tests, code, and review findings. If a needed concept
is absent, reconsider whether the task is inventing language; record a genuine gap for the
`domain-modeling` skill.

Surface any contradiction with an accepted ADR explicitly instead of silently overriding it.
